# Solitude-Theme-port-for-Ghostty-on-Mac-and-Helix-Editor
This repo is my own port of Hancore/Linux's Solitude Theme for Ghostty and Helix Editor. It includes minor changes to the pallets to improve warning and error colours along with better readability in helix editor. Although in the current state the theme for Ghostty is close to completion but the helix editor theme requires improvement.

to add the theme drag and drop the config.ghostty file to ~/.config/ghostty/ directory for linux or macOS.
drag and drop the helix solitude file into ~/.config/ghostty/themes/ directory inside the ghostty directory.

drag and drop the solitude.toml file for helix editor theme into the ~/.config/helix/themes/ directory
